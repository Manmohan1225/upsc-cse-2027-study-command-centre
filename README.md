# UPSC CSE 2027 Study Command Centre (v2)

Start date: 11 November 2026. Prelims: 23 May 2027. Mains begins: 20 August 2027.

## Upload to GitHub
Replace the existing `index.html`, `styles.css`, `icon.svg`, and `README.md`, and add `app.js`, `manifest.json`, `sw.js`, `icon-192.png`, and `icon-512.png` to the repository root. Commit all changes. In GitHub Pages keep `main` and `/(root)`.

## Install
Open the HTTPS GitHub Pages URL in Chrome. After the new files deploy, refresh the page. Chrome should detect the web app manifest and service worker. If Install app is still unavailable, use Add to Home screen / Create shortcut.

## Features
Daily checklist and timetable, date-specific Chemistry and GS targets, syllabus tracker, test log, study-hour and notes log, backup/restore, offline cache, local-device storage.

Data is stored in this browser on this device. Export backups regularly. Clearing browser data can erase records.
